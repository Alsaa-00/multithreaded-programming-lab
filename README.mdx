# Multithreaded Programming Using Pthreads and OpenMP

This project demonstrates multithreaded programming using POSIX Threads (Pthreads) and OpenMP.

## Part A - Pthreads

- Thread creation
- Multiple threads
- Parallel summation
- Race condition
- Mutex synchronization
- Performance measurement

## Part B - OpenMP

- Parallel regions
- Work sharing
- Reduction
- Race condition
- Critical section
- Barrier synchronization
- Performance measurement

## Part C - Performance Analysis

The programs were tested using:

- 1 thread
- 2 threads
- 4 threads
- 6 threads
- 16 threads

Execution time, speedup and efficiency were measured and compared.

## Environment

- Ubuntu on WSL 2
- GCC
- Pthreads
- OpenMP
